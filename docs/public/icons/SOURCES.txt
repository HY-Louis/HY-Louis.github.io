Local edits to the downloaded files (nothing else was changed):
  - removed the inline style="flex:none;line-height:1" and set width/height to 24;
  - replaced fill="currentColor" with a fixed ink colour #14161a in openai.svg, cursor.svg and
    qoder.svg: an SVG loaded through <img> cannot inherit the page colour, so currentColor
    would always render black. These three are marked class="ico ico-mono" in the page and get
    filter:invert(1) hue-rotate(180deg) in dark mode (see assets/site-pages.css).
  - kimi.svg: the K in the downloaded file is fill="#fff" because the mark is drawn to sit on the
    black Kimi tile (see the official app icon at https://www.kimi.com/pwa-192.png), so on this
    paper-coloured page only the small blue corner dot was visible. The K is now #14161a and the
    file is marked ico-mono, which reproduces Kimi's own behaviour — their site ships
    favicon-light.ico (black mark) and favicon-dark.ico (white mark). The #1783FF corner dot is
    unchanged.
