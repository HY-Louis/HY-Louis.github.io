AI 工具

写代码、查资料、改文章都用得上。同一个问题多问两个模型，答案更稳。

AGENT Hermes Agent Nous Research 出的开源 AI Agent 框架。想搞清楚一个 Agent 是怎么跑起来的，可以从它入手。 hermes-agent.nousresearch.com
免费 DeepSeek 国产大模型，网页版和 App 免费。写代码、讲概念都很顺手，国内直连不用折腾网络。 deepseek.com
CLI Claude Code Anthropic 的命令行编程助手，直接在终端里读写你的项目文件。这个网站就是用它做出来的。 claude.com/claude-code
Claude Anthropic 的对话版。长文本理解和代码解释强，读论文、理清一门课的脉络时好用。 claude.ai
OpenAI ChatGPT 背后的公司。官网看模型发布和 API 文档，日常对话直接去 chatgpt.com。 openai.com
IDE Qoder CN 阿里出的 AI 编程 IDE 中国站。能整体理解代码库，把复杂任务委托给 AI 代理执行。 qoder.com.cn
IDE Cursor 目前最流行的 AI 编辑器，基于 VS Code 改造。和 Qoder 是同类，二选一用熟就行。 cursor.com
学生免费 GitHub Copilot 装在 IDEA / VS Code 里的代码补全。用学校邮箱认证 GitHub 学生包可以免费用。 github.com/features/copilot
Gemini Google 的模型。多模态和长上下文强，看图讲题、整理一整本 PDF 讲义时可以用。 gemini.google.com
免费 Kimi 月之暗面的模型，长文档能力好。丢一篇论文进去让它先讲一遍，再自己精读。 kimi.com

刷题平台

灵神题单定顺序，LeetCode 做题，洛谷和蓝桥杯官网备赛。

推荐 灵神题单 · 如何科学刷题 LeetCode 中文社区公认最系统的刷题顺序，按专题递进，不用自己瞎挑题。 leetcode.cn
LeetCode 题库 按标签和难度筛题，刷题主战场。 leetcode.cn
洛谷 国内算法竞赛刷题站，蓝桥杯备战主要靠它。 luogu.com.cn
蓝桥杯官网 报名、赛程、真题和模拟赛都在这里。 dasai.lanqiao.cn
八股 小林 coding 图解计网、操作系统、MySQL、Redis 的面试知识点。面试前背八股就从这里背。 xiaolincoding.com

开发工具

写代码之前先把这些装好。

学生免费 IntelliJ IDEA Java 开发的主力编辑器。社区版免费，用学校邮箱申请 JetBrains 学生包能解锁旗舰版。 jetbrains.com/idea
DataGrip 图形化的数据库管理工具，看表、写 SQL 比命令行直观得多。 jetbrains.com/datagrip
Apifox 接口测试工具。写完后端接口，用它验证能不能返回正确数据。 apifox.com
Git 官网 下载安装包的地方。代码存档和「后悔药」工具，所有项目都要用。 git-scm.com
Docker 官网 下载 Docker Desktop。Windows 上装之前要先开 WSL2。 docker.com
免费 VS Code 轻量万能编辑器。看前端代码、改配置文件、写 Markdown 笔记都用它，比 IDEA 启动快。 code.visualstudio.com

英语与竞赛

报名 四六级报名系统 教育部考试中心官方报名入口。四级、六级报名都从这里进。 cet-bm.neea.edu.cn
报名 美赛 MCM / ICM 官网 美国大学生数学建模竞赛主办方 COMAP 官网。报名、赛题和历年优秀论文都在这里。 comap.com
报名 蓝桥杯大赛官网 报名、缴费、查赛场都在这里。 dasai.lanqiao.cn
