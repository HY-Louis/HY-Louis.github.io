10

Java 路线推进

十月 · 快速打穿基础模块，同时接住期中

0 / 0
MySQL 数据库 打开视频

总共给自己 5 天，只看前 50 讲。剩下的索引、事务、隔离机制这些高级内容不用现在花时间，面试前背八股即可。

JDBC 半天学完 打开视频

只用半天。重点是理解「Java 代码怎么跟数据库说上话」，不用背 API。

JavaWeb 打开视频

第 5-30 讲跳过（前端基础语法部分），直接进后端核心内容。这门课是从「会写 Java」到「会写网站」的分水岭。

Git 版本控制 打开视频

一定要动手实践，光看不练等于没学。Git 是给代码存档和写「后悔药」的工具，以后所有项目都要用。

Linux 基本命令 打开视频

服务器上跑的东西基本都是 Linux。学会在命令行里操作文件、装软件就够了。

Docker 容器 打开视频

Docker 相当于把软件和它的运行环境一起装进一个「集装箱」，换台电脑也能原样跑起来，不用再折腾环境。

SpringBoot Java 后端核心 打开视频

SpringBoot 是 Java 做后端最主流的框架，11 月的苍穹外卖项目就建立在它上面。这门要学扎实。

LeetCode · 灵神题单 每日刷 打开题单

从 10 月开始每天刷，一直保持到学年结束。保持手感比单次刷多更重要。

期中考试复习 第 6、7 周

第 6、7 周要开始复习期中考试——到这两周就把上面的课往后放，先保成绩（这学期 GPA 目标是 3.0+）。

操作系统 · 计算机组成原理 持续

两门硬课不停，跟着课表进度走，别攒着。

本月节奏：这是一个「广撒网」的月份，七门课压在一起。如果时间不够，优先级是 MySQL → JavaWeb → SpringBoot → Git，Linux 和 Docker 可以稍微往后挪一点，但别整个跳过。
