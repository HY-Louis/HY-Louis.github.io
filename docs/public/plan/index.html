关于 API 的说明：

很多初学者问：API 记不住怎么办？

关于 API，可以直接问 AI，连 API 文档都不需要了。那都是旧时代的产物，现在也过时了，不好用。而且现在 JavaSE 接触到的很多 API 其实在后面做项目的时候都用不到，都是被淘汰的 API，看看就行，别太讲究。

Git 版本控制 打开视频

一定要动手实践，光看不练等于没学。Git 是给代码存档和写「后悔药」的工具，以后所有项目都要用。

Linux 基本命令 打开视频

服务器上跑的东西基本都是 Linux。学会在命令行里操作文件、装软件就够了。

Docker 容器 打开视频

Docker 相当于把软件和它的运行环境一起装进一个「集装箱」，换台电脑也能原样跑起来，不用再折腾环境。

SpringBoot Java 后端核心 打开视频

SpringBoot 是 Java 做后端最主流的框架，苍穹外卖项目就建立在它上面。这门要学扎实。

本阶段优先级：MySQL → JavaWeb → SpringBoot → Git；Linux 和 Docker 可以稍微往后挪一点，但别整个跳过。
03

项目实战

阶段三 · 把学到的知识放进一个能跑起来的项目

苍穹外卖 · 项目实战 重点项目 打开视频
学习要求（共 200 节）
节次要求说明
1 – 170必须听这个项目太经典，所以主播就让全学了；后面 30 节是前端，没必要
作业要求：线下的作业如果时间紧可以不写；但是线上出视频讲的代码绝对要自己写一遍，别偷懒！
主播的提醒：学习的时候，有一段时间会进入一个写增删改查的舒适区。如果你没有这种感觉那就无所谓；如果有，别写了，往后继续学！你后面还有很多技术栈要学，别为你那丑陋的代码搁那沾沾自喜了，后面你会很尴尬。
结尾验收要求

做完这个项目，拿一份接口文档、定义好的数据库表，以及一个刚开始写的项目（例如小商城），应该能做到下面四件事：

  1. 写实体类。
  2. 通过各种包、定义 Java 文件，框框把代码写出来。
  3. 在 Apifox 点击测试，能返回预期数据。
  4. 前端打开页面，可以看到返回的数据被渲染出来。
Redis 缓存 打开视频

Redis 是把常用数据放在内存里的「高速缓存」，用来给数据库减压。苍穹外卖里刚好用到，学完就能对照着理解。

本阶段节奏：苍穹外卖是重点，占了大部分时间；Redis 跟着项目一起学，边用边理解。
